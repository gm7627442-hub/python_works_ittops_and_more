Домашнее задание 2

1. Что делает main.jsx и почему он важен?
main.jsx является точкой входа приложения. Он находит элемент root в index.html и отображает в нём главный компонент App с помощью ReactDOM.createRoot.

2. Что подключается в index.html и почему он почти пустой?
В index.html находится элемент div с id="root" и подключается main.jsx. Файл почти пустой, потому что содержимое страницы создают React-компоненты.

3. Зачем нужен App.jsx? Что в нём изменено?
App.jsx содержит главный компонент приложения. В нём изменяют JSX-разметку, которая отображается пользователю.

4. Что находится в package.json и какую роль он играет?
package.json хранит название и версию проекта, список зависимостей и команды для запуска, сборки и проверки приложения.

Дополнительные команды:
npm run dev — запускает сервер разработки.
npm run build — создаёт готовую сборку проекта.
npm run preview — запускает просмотр готовой сборки.
